## Product rules preserved

LLMs cannot override objective test correctness, elapsed time, entitlement or progression rules. Numerical readiness requires sufficient stored evidence. Sources need applicability and freshness checks, not just citations. Candidate code runs only in separate hardened infrastructure. Integrity signals are contextual observations, not automatic accusations. Reports and employer-style rounds clearly identify themselves as simulations.

## Deliberate adaptations

The source proposes Next.js/TypeScript and eventual Java support. The user's Python requirement takes precedence: UI authoring and all project implementation use Python, and candidate coding initially remains Python. Source Phase 0 is absorbed into repository Phase 1 so the requested Phase 1/Phase 2 sequence begins with an actionable foundation. Full browser proctoring requires a later feasibility decision and is not promised by the initial Python UI prototype.
